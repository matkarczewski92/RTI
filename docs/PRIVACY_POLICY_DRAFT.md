# Privacy Policy Draft

Draft status: this is a working draft for Reptile Tycoon and must be reviewed before Google Play publication. It is not final legal advice.

## App

Reptile Tycoon is a mobile idle tycoon game for Android.

## Current MVP Data Handling

The current MVP is designed with:

- no user account system,
- no server backend,
- no ads,
- no in-app purchases,
- no analytics,
- local save data only.

## Local Save Data

The game stores progress locally on the player's device. Local save data may include gameplay progress such as currency, XP, level, settings, habitats, reptiles, discovered variants, quests, achievements, workers, upgrades, and offline progress timestamps.

The current save path in the Godot project is:

```text
user://save_game.json
```

This data is used to restore gameplay progress on the same device.

## Data Collection

In the current MVP, Reptile Tycoon does not intentionally collect personal data on a server because the game has no account system and no backend service.

## Ads and Purchases

The current MVP does not include ads, AdMob, in-app purchases, Google Play Billing, premium shop, or Play Pass features.

If ads, purchases, analytics, accounts, cloud save, or external SDKs are added later, this policy and the Google Play Data Safety form must be updated before release.
