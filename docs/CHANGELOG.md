## v0.1.1
EN
This update improves offline balance, background behavior, adds new content, and refreshes several key interface elements.

- Added a new reptile to the Dry Prairie biome for the Jungle habitat.
- Rebalanced offline stat decay: reptile stats now decrease more slowly and predictably while the player is away.
- Minimized gameplay is now treated as offline time, so returning to the app correctly applies time-based changes.
- Redesigned the Workers window with a more compact, readable layout optimized for phone screens.
- Improved the placement of worker icons, descriptions, costs, and purchase/upgrade buttons.
- Updated the tutorial bubble icon and improved the layout of the task card.
- Expanded the task card content area so text, progress, rewards, and the claim button are better aligned.
- Redesigned the offline reward popup to better match the game’s visual style.
- Preserved the existing behavior of workers, tasks, tutorial flow, and offline rewards.
- Added Emerald Tree Skink (Scynk Szmaragdowy) as a new reptile species in the Dry Prairie biome.
- Added collection achievement for discovering all Emerald Tree Skink variants.
- Improved the gender selection UI on reptile cards in the shop.

This update improves readability, usability, visual consistency, content variety, and the overall offline gameplay experience.

PL
Ta aktualizacja poprawia balans trybu offline, działanie gry w tle, dodaje nową zawartość oraz odświeża kilka kluczowych elementów interfejsu.

- Zbalansowano spadek statystyk w trybie offline: statystyki gadów zmniejszają się teraz wolniej i bardziej przewidywalnie, gdy gracz jest poza grą.
- Zminimalizowana gra jest teraz traktowana jak czas offline, więc po powrocie do aplikacji poprawnie naliczane są zmiany wynikające z upływu czasu.
- Przebudowano okno Pracowników, dodając bardziej kompaktowy i czytelny układ zoptymalizowany pod ekrany telefonów.
- Poprawiono rozmieszczenie ikon pracowników, opisów, kosztów oraz przycisków zakupu/ulepszenia.
- Zaktualizowano ikonę dymka samouczka oraz poprawiono układ karty zadania.
- Poszerzono obszar treści karty zadania, dzięki czemu tekst, postęp, nagrody i przycisk odbioru są lepiej wyrównane.
- Przebudowano okno nagrody offline, aby lepiej pasowało do stylu wizualnego gry.
- Dodano nowego gada do biomu Dry Prairie dla habitatu Dżungla.
- Dodano Scynka Szmaragdowego (Emerald Tree Skink) jako nowy gatunek gada w biomie Dry Prairie.
- Dodano osiągnięcie kolekcjonerskie za odkrycie wszystkich wariantów Scynka Szmaragdowego.
- Poprawiono UI wyboru płci w kartach gadów w sklepie.

Aktualizacja poprawia czytelność, wygodę obsługi, spójność wizualną, różnorodność zawartości oraz ogólne doświadczenie rozgrywki offline.
