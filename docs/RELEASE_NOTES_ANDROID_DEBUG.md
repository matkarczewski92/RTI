# Reptile Tycoon v0.1.0-debug - Android MVP test build

## What is included

- One playable biome.
- Habitats.
- Reptile purchase.
- Reptile assignment.
- Reptile management.
- Care actions.
- Active income.
- Offline progress.
- Quests.
- Achievements.
- Workers/upgrades if implemented.
- Local save.
- Settings/language if implemented.

## What to test

- Install and first launch.
- Portrait layout on the device.
- Welcome screen to biome map flow.
- Main biome view.
- Habitat purchase and build timer.
- Reptile shop purchase.
- Reptile assignment and unassignment.
- Reptile management and care actions.
- Active income and reward claiming.
- Save/load after app close.
- Offline progress after app close.
- Minimize/resume.
- Quest and achievement screens.
- Touch comfort on phone.

## Known limitations

- Balance is not final.
- Graphics are not final in all places.
- No ads.
- No purchases.
- No cloud save.
- No online account.
- No Play Games integration.

## Not included yet

- Ads or AdMob.
- In-app purchases.
- Google Play Games Services.
- Analytics.
- Cloud save.
- Account system.
- New biomes as playable content.
- Breeding, eggs, or incubator systems.

## Feedback format

Please report issues with:

- Device model.
- Android version.
- Steps to reproduce.
- Screenshot/video if possible.
- Expected result.
- Actual result.
