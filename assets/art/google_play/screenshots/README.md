# Google Play Screenshots

Prepare screenshots from the real Android build or an emulator running the current stable UI. Do not generate fake screenshots for the store listing.

## Orientation

Reptile Tycoon is a portrait mobile game. Capture screenshots in portrait orientation.

## Recommended Capture Resolutions

Good phone screenshot examples:

- 1080x1920
- 1080x2400
- 720x1600
- 1440x2960

Use a consistent device/resolution set when possible.

## Minimum MVP Screenshot Set

- Welcome screen.
- Biome map.
- Main biome gameplay.
- Habitat management.
- Reptile management.
- Shop.
- Tasks / achievements.

## Suggested File Names

- `screenshot_01_welcome.png`
- `screenshot_02_biome_map.png`
- `screenshot_03_main_gameplay.png`
- `screenshot_04_habitat_management.png`
- `screenshot_05_reptile_management.png`
- `screenshot_06_shop.png`
- `screenshot_07_tasks_achievements.png`

## Capture Notes

- Use the current phone-tested Android MVP build.
- Avoid showing debug overlays, console text, broken UI, or placeholder-only screens.
- Keep screenshots honest: show only features available in the uploaded build.
- Prefer clean saves with readable progress, visible habitats, and clear reptile management UI.
